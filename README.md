# Red-harvest
An extensible Python media downloader built on top of yt-dlp, featuring video/audio downloads, quality selection, playlist support, customizable output, and both CLI and GUI interfaces. 
_____________________________________
## Features

- Download videos ✔
- Download audio
- Quality selection
- Playlist support
- Custom download directory
- Automatic file renaming
- Progress bar
- CLI & GUI
